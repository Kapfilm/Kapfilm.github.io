# Kapfilm — приложения для macOS

Персональный сайт приложений Kapfilm. Публикуется через GitHub Pages по адресу:

<https://kapfilm.github.io>

## Локальный просмотр

Сайт не требует сборки. Откройте `index.html` или запустите простой локальный сервер:

```bash
python3 -m http.server 8000
```

После этого откройте <http://localhost:8000>.

## Как добавить программу

1. Скопируйте иконку в `assets/images/`.
2. В `index.html` добавьте ещё одну карточку `<article class="app-card">` в секцию `#apps`.
3. Укажите название, описание, требования и ссылку на GitHub Releases.
4. Проверьте страницу в светлой и тёмной темах, а также на узком экране.

Готовые DMG и ZIP следует публиковать через GitHub Releases соответствующего проекта, а не хранить в этом репозитории.
